# Changelog

## 0.1.1 - 2026-09-28

- Added per-page `{{output_extension ...}}` metadata for generating files such as `.php`.
- Updated Markdown link rewriting and sitemap discovery for custom output extensions.

## 0.1.0 - 2026-06-18

- Added the Documint public documentation pages for GitHub Pages.
- Added Markdown-to-HTML generation with templates and sidebars.
- Added page list and category page generation.
- Added multi-category support for topic, audience, importance, and author views.
- Added Mermaid, PlantUML, source block, raw HTML, and Markdown link rewriting examples.
- Added GitHub Actions deployment for the generated documentation site.
